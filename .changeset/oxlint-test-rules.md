Add the `@elmeragroup/internal/oxlint/tests` entry, a default-exported Oxlint plugin of test-shape rules to register as `tests`: `no-test-retry` (a `retry`, `repeats` or `retries` option on a test, suite, `vi.setConfig` or test config), `no-wall-clock` (an elapsed real-clock time that is subtracted or asserted), `no-fixed-delay` (a non-zero timer, `sleep`, `delay` or `page.waitForTimeout` outside a fake clock or polling loop), `no-source-reading-tests` (reading a code module's text or a `?raw` import of one), `no-class-assertions` (asserting a class the test did not supply) and `no-geometry-assertions` (a measured layout length against a pixel number). `no-fixed-delay` takes `waitHelpers`, `realWaitHelpers` and `fakeClockHelpers` options, and `no-wall-clock` takes `fakeClockHelpers`, for a repository's own wait and fake-clock helpers. The `@elmeragroup/internal/oxlint` plugin adds `require-disable-reason`, which requires `--` and a reason of at least eight non-space characters on every `oxlint-disable` and `eslint-disable` comment; its `directives` and `rules: "one"` options can limit a path to next-line disables that name one rule. Importing the new entry does not load TypeScript or Effect.
